# EFM8LB1 Phasor Calculator & Signal Analyzer 
- A microcontroller-based digital signal analyzer and phasor calculator built around the Silicon Labs EFM8LB1 microcontroller. This project samples dual analog input channels, computes real-time RMS voltage, frequency, and phase relationships, and provides an interactive interface for performing complex phasor arithmetic using hardware pushbuttons.

## Features:
- ### High-Speed Analog Sampling: Configured for a 72 MHz system clock and a 14-bit ADC mode to maximize measurement accuracy.
- Real-Time Signal Analysis: Measures and calculates:Reference and signal RMS amplitudes.   Signal frequency.   Phase difference between channels using precision hardware timers (Timer2 and Timer3).   Custom 8051-Optimized Math Library: Implements lightweight floating-point approximations for sin, cos, sqrt, atan, and atan2 designed for efficient execution on 8051 architectures.   Interactive Phasor Calculator: Features dedicated pushbuttons to perform vector/phasor operations directly on the device:Add / Subtract: Converts polar coordinates to rectangular form, performs vector addition/subtraction, and converts results back to magnitude and phase.   Multiply: Multiplies magnitudes and adds phase angles.   Save: Captures current RMS and phase metrics into selectable bus registers.   Dual-Interface Output: Real-time telemetry streamed via UART to a terminal emulator (e.g., PuTTY) alongside a live 16x2 character LCD status display.   Hardware RequirementsMicrocontroller: Silicon Labs EFM8LB1 (supported on evaluation boards like the EFM8 Laser Bee).   Display: Standard 16x2 character LCD (operating in 4-bit mode).   Inputs:Analog inputs configured on port pins (e.g., P2.2, P2.3).   Pushbuttons for arithmetic operations (ADD, SUB, MUL, SAVE, and DISPLAY) mapped to designated GPIO pins.   Communication: USB-to-UART bridge for debug logging and telemetry.   Code Architecture_c51_external_startup(): Initializes system clock routing (up to 72 MHz), watchdog timer disable sequences, and UART configuration.   InitADC(): Configures ADC gain, tracking time, and 14-bit conversion settings.   Measurement Loop: Continuously polls input pins for zero-crossings, calculates periods and time deltas using timer captures, and updates peak voltages.   Phasor Engine: Executes rectangular-polar transformations for vector addition and subtraction using custom trigonometric routines.
